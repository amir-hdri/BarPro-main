fix(frontend): comprehensive resolution of frontend bugs and technical debt

1. **Duplicate Imports**:
   - Removed duplicated imports in `apps/web/src/app/page.tsx` and `apps/web/src/app/history/page.tsx`.
   - Setup `eslint-plugin-unused-imports` in `package.json` and `.eslintrc.json` (replacing `eslint.config.mjs`) to detect unused/duplicate imports.
   - Fixed missing `</main>` closing tag in `apps/web/src/app/auth/page.tsx` during linting.
2. **Lockfile Conflict & Engine Requirements**:
   - Deleted `apps/web/package-lock.json` keeping `yarn.lock` as the single lockfile.
   - Added `engines` object in `package.json` to enforce `node >=18.17.0` and `yarn >= 1.22.0`.
   - Removed `.npmrc` since it pointed to a registry that was timing out.
3. **Zod Schema Mismatch**:
   - Removed `.default("active")` from `status` field in `CreateClientModal.tsx` to match the non-optional string expected by `react-hook-form`.
4. **Missing Data Interface**:
   - Added `driver_name?: string;` to `WaybillJob` interface in `apps/web/src/lib/types.ts`.
5. **Infinite Loop Risk in useEffect**:
   - Replaced `[role]` with `[client?.role]` in the `useEffect` dependencies inside `apps/web/src/app/page.tsx` to stabilize the data fetching logic.
6. **Next.js Config Turbopack Error**:
   - Removed the `turbopack` key from `apps/web/next.config.mjs` to prevent the unrecognized key warning.
7. **Startup Script Port Conflict**:
   - Added `fuser -k 3000/tcp || true` inside `scripts/start_system.sh` to forcefully free port 3000 before the frontend attempts to bind to it, preventing orphan processes from failing the script.
