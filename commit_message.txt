🧪 [testing] Improve coverage for create_telemetry_event

🎯 **What:** The testing gap addressed
The create_telemetry_event helper function in app/schemas/enterprise_reporting.py lacked comprehensive tests for optional arguments and schema validation edges, like incorrect statuses or negative execution duration.

📊 **Coverage:** What scenarios are now tested
- Added test_create_telemetry_event_full_args to ensure all optional parameters correctly populate the dictionary.
- Added test_create_telemetry_event_default_metadata to verify the metadata dictionary fallbacks to empty correctly.
- Added test_create_telemetry_event_invalid_status to ensure schema validation fails for a bad status.
- Added test_create_telemetry_event_negative_duration to ensure schema validation fails for negative durations.

✨ **Result:** The improvement in test coverage
We now thoroughly validate edge conditions and all optional parameters inside the telemetry schema parsing layer. Tests verify pydantic.ValidationError is triggered cleanly on schema violations.
