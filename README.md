> **تحولی در مدیریت حمل و نقل:** سیستم BarPro یک راهکار سازمانی (Enterprise) چند مستاجره برای خودکارسازی کامل فرآیند ثبت بارنامه در سامانه UTCMS است. این پروژه با استفاده از معماری Monorepo، بک‌انـد پرقدرت FastAPI و فرانت‌انـد مدرن Next.js، پایداری و سرعت بی‌نظیری را ارائه می‌دهد.

---

## 💎 ویژگی‌های شاخص سیستم

### 🏢 معماری چند مستاجره (Multi-tenant)
- **جداسازی کامل داده‌ها:** هر مشتری (Tenant) به محیطی کاملاً ایزوله دسترسی دارد.
- **مدیریت ناوگان اختصاصی:** هر شرکت می‌تواند رانندگان و ناوگان خود را به صورت مستقل مدیریت کند.
- **سرویس مستر ادمین:** پنل اختصاصی برای مدیریت کلی سیستم، ساخت مشتریان جدید و نظارت بر تراکنش‌ها.

### 🤖 موتور RPA پیشرفته و هوشمند
- **هوشمندی در انتخاب مکان:** انتخاب مبدا و مقصد از طریق نقشه تعاملی، جستجوی متنی یا منوهای آبشاری با قابلیت Geocoding.
- **خودترمیمی (Self-healing):** شناسایی خودکار تغییرات در سایت مقصد و استفاده از سلکتورهای جایگزین.
- **پشتیبانی از حالت تجمیعی (Tajmi):** بهینه‌سازی شده برای ثبت‌های انبوه و ناوگان‌های سنگین.
- **مدیریت هوشمند کپچا:** حل خودکار کپچاهای محاسباتی و تصویری با موتور CNN.

### 🔐 امنیت و پایداری سازمانی
- **رمزنگاری دو لایه:** استفاده از AES برای داده‌های حساس و JWT برای احراز هویت.
- **مدیریت خطا با Retry Logic:** جلوگیری از قطع شدن عملیات در صورت نوسانات شبکه با مکانیزم Exponential Backoff.
- **پایداری نشست (Session Persistence):** مدیریت هوشمند کوکی‌ها برای کاهش نیاز به لاگین مجدد.

## 🛠️ ساختار مهندسی پروژه

```text
/
├── app/                    # هسته بک‌انـد (FastAPI)
│   ├── api/                # لایه API نسخه v1 با تفکیک مسیرها
│   ├── automation/         # موتور RPA (Authenticator, Location, Waybill)
│   ├── core/               # تنظیمات پایه، امنیت و مدیریت شبکه
│   ├── models/             # مدل‌های داده (SQLModel / SQLAlchemy)
│   ├── schemas/            # اعتبارسنجی ورودی/خروجی (Pydantic)
│   └── services/           # منطق تجاری و مدیریت مستاجرین
├── apps/
│   └── web/                # فرانت‌انـد مدرن (Next.js 14, Tailwind, TypeScript)
├── alembic/                # لایه مهاجرت و تاریخچه تغییرات دیتابیس
├── docs/                   # مستندات جامع (راهنمای نصب، دیتابیس، API)
└── scripts/                # ابزارهای مدیریتی، مانیتورینگ و راه‌اندازی سریع
```

## 🚀 راه اندازی سریع (Deployment)

### ۱. نصب پیش‌نیازها
ابتدا پایتون ۳.۱۱ و Node.js ۱۸ به بالا را نصب کنید.

```bash
# نصب وابستگی‌های بک‌انـد
pip install -r requirements.txt

# نصب وابستگی‌های فرانت‌انـد
cd apps/web && npm install && cd ../..
```

### ۲. تنظیمات محیطی (.env)
یک فایل `.env` بر اساس نمونه موجود بسازید و مقادیر مربوط به دیتابیس و کلیدهای امنیتی را در آن قرار دهید.

### ۳. اجرای سیستم
سریع‌ترین راه برای اجرای کل سیستم استفاده از اسکریپت‌های بهینه‌سازی شده است:

```bash
./scripts/start_system.sh
./scripts/stop_system.sh

```

## 📈 دستورات کلیدی مدیریت سیستم

| دستور | توضیحات |
|-------|---------|
| `./scripts/check_health.sh` | بررسی سلامت دیتابیس، Redis و API |
| `alembic upgrade head` | بروزرسانی ساختار دیتابیس به آخرین نسخه |
| `./scripts/view_logs.sh follow` | مشاهده آنلاین لاگ‌های سیستم |
| `./scripts/reset_database.sh` | پاکسازی کامل و راه‌اندازی مجدد دیتابیس |
