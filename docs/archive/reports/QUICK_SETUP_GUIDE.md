# بررسی سلامت و اجرای پروژه UTCMS (BarPro)

من تمام قسمت‌های پروژه از جمله فرانت‌اند، بک‌اند و دیتابیس را بررسی کردم.

## کارهای انجام شده:
1. **نصب وابستگی‌ها**: تمام وابستگی‌های Python در بک‌اند و Node.js در فرانت‌اند با موفقیت نصب شدند.
2. **بررسی تست‌ها**: مشکل مربوط به `is_retryable` در کلاسیفیکیشن‌های فاز ۱ RPA رفع شد. تمامی تست‌های مرتبط به دلیل رفع مشکل import‌ها (مانند SQLModel و FastAPI) و Mock Objectها از جمله `test_driver_multitenant.py` و `test_rpa_phase1_architecture.py` با موفقیت بررسی و Pass شدند.
3. **تغییرات دیتابیس**: جداول دیتابیس با اضافه کردن ایمپورت تمامی مدل‌ها قبل از فرآیند `create_all` رفع مشکل شد.
4. **تغییرات فرانت‌اند**: مشکل ماژول نصب‌نشده `zod/v4` با تغییر کانفیگ‌ها و نصب درست انجام و در نهایت بیلد (build) موفقیت‌آمیز فرانت‌اند Next.js تایید شد.

پروژه آماده اجرا در محیط Production می‌باشد.

## راهنمای کامل راه‌اندازی و پیش‌نیازها

### پیش‌نیازهای سیستم
* **Python**: نسخه 3.11 یا بالاتر (پیشنهاد: 3.12)
* **Node.js**: نسخه 20 یا بالاتر
* **دیتابیس**: PostgreSQL نسخه 16 یا بالاتر
* **Cache/Queue**: Redis نسخه 7 یا بالاتر
* **سیستم‌عامل**: لینوکس (توصیه شده Ubuntu 22.04+) یا محیط داکر

### مرحله ۱: تنظیمات بک‌اند (Python FastAPI)

1. **نصب پکیج‌ها**:
   `pip install -r requirements.txt`
   `playwright install chromium`

2. **تنظیم فایل‌های محیطی**:
   فایل `.env.example` را به `.env` کپی کنید و اطلاعات دیتابیس و سایر متغیرها را مقداردهی کنید:
   `cp .env.example .env`

   **متغیرهای کلیدی:**
   * `DATABASE_URL`: آدرس اتصال به Postgres
   * `REDIS_URL`: آدرس اتصال به Redis
   * `JWT_SECRET`: یک رشته امن و طولانی برای امضای توکن‌ها
   * `FRONTEND_URL`: `http://localhost:3000` (برای توسعه محلی)

3. **ایجاد دیتابیس (Migration)**:
   `alembic upgrade head`

### مرحله ۲: تنظیمات فرانت‌اند (Next.js)

1. **نصب پکیج‌ها**:
   در پوشه apps/web: `yarn install`

2. **تنظیم فایل محیطی فرانت‌اند**:
   یک فایل `.env.local` در پوشه `apps/web` بسازید و آدرس API را مشخص کنید:
   `NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1`

### مرحله ۳: اجرای سرویس‌ها

برای اجرای سیستم به‌صورت کامل (بدون داکر) به سه ترمینال نیاز دارید:

1. **ترمینال ۱ (بک‌اند)**:
   `uvicorn app.main:app --host 0.0.0.0 --port 8000`

2. **ترمینال ۲ (Celery Worker برای RPA)**:
   `celery -A app.workers.celery_app worker --loglevel=info -Q waybill_tasks,rpa_auth,rpa_submit`

3. **ترمینال ۳ (فرانت‌اند)**:
   توسعه: `yarn dev &`
   پروداکشن: `yarn build && yarn start`

### مرحله ۴ (پیشنهادی): اجرای کامل با Docker Compose

اگر ترجیح می‌دهید از داکر استفاده کنید، همه پیش‌نیازها و سرویس‌ها با هم اجرا خواهند شد:

`docker compose up -d --build`

این دستور کانتینرهای زیر را اجرا می‌کند:
* `postgres` (پورت 5432)
* `redis` (پورت 6379)
* `backend` (FastAPI روی پورت 8000)
* `celery_worker` (اجرای پردازش‌های پس‌زمینه)
* `frontend` (Next.js روی پورت 3000)

اکنون می‌توانید از طریق آدرس `http://localhost:3000` به پنل کاربری دسترسی داشته باشید.
