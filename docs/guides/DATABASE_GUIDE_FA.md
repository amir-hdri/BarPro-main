# 📖 راهنمای نگهداری و بروزرسانی دیتابیس (BarPro)

با توجه به تغییرات مداوم در ساختار پروژه و مدل‌های داده، رعایت نکات زیر برای حفظ پایداری سیستم ضروری است.

## ۱. بروزرسانی ساختار دیتابیس (Migration)
هر زمان که کد جدیدی دریافت می‌کنید یا تغییری در مدل‌های `app/models_multitenant.py` ایجاد می‌شود، باید دیتابیس را با آخرین تغییرات هماهنگ کنید.

**دستور بروزرسانی:**
```bash
alembic upgrade head
```
این دستور بدون حذف داده‌های قبلی، ستون‌ها یا جداول جدید را اضافه می‌کند.

## ۲. بررسی وضعیت فعلی
برای اینکه بدانید دیتابیس شما در کدام نسخه است، از دستور زیر استفاده کنید:
```bash
alembic current
```

## ۳. زمان مناسب برای ریست کامل (Reset)
در صورتی که با خطای `DuplicateTable` یا تداخل در قیدها (Constraints) مواجه شدید و داده‌های موجود برایتان اهمیت حیاتی ندارند، بهترین راه ریست کامل است.

**دستور ریست (هشدار: همه داده‌ها پاک می‌شوند):**
```bash
./scripts/reset_database.sh
```

## ۴. نکات مهم امنیتی و پایداری
- **بک‌آپ:** همیشه قبل از اجرای `upgrade head` در محیط عملیاتی، از دیتابیس خود نسخه پشتیبان تهیه کنید.
- **تغییرات دستی:** هرگز جداول دیتابیس را به صورت دستی (از طریق pgAdmin یا psql) تغییر ندهید؛ همیشه از `alembic` استفاده کنید تا یکپارچگی کد و دیتابیس حفظ شود.
- **محیط توسعه:** در محیط توسعه (Local)، اگر با خطای عجیبی مواجه شدید، ابتدا `reset_database.sh` را اجرا کرده و سپس مجدداً `upgrade head` بزنید.
